# JOJO_memes
**此庫只限於上傳JOJO_meme，請勿上傳其他不相關圖片。** <br>
**圖片格式目前僅限於「.jpg」、「.jpeg」、「.png」。** <br><br>

<h2># 🖼️ 梗圖投稿指南 (How to Contribute):
<h3>1. 擁有一個Github帳號，若是沒有的話，就去辦一個。
  
<h3>2. Fork（複製儲存庫）
<h4>&emsp;1. 進入本專案的主頁面。
<h4>&emsp;2. 點擊右上角的 [Fork] 按鈕（這會把這個專案複製一份到你自己的帳號底下）。

<h3>3. 上傳圖片
<h4>&emsp;1. 進入你剛才 Fork 到自己帳號裡的專案頁面。
<h4>&emsp;2. 點擊上方檔案列表右側的 [Add file] 按鈕，然後選擇 [Upload files]。
<h4>&emsp;3. 檔名盡量符合圖片文字敘述，或是以關鍵字當作檔名。

<h3>4. Commit（提交變更)
<h4>&emsp;1. 圖片上傳完成後，把網頁畫面往下拉，會看到 "Commit changes" 區塊。
<h4>&emsp;2. 寫一下簡單的說明（例如：「新增 2 張梗圖」）。
<h4>&emsp;3. 點擊綠色的 [Commit changes] 按鈕，將圖片正式存入你自己的倉庫中。

<h3>5. 發起 Pull Request (PR)
<h4>&emsp;1. 提交完成後，網頁會自動跳回你自己的專案首頁。
<h4>&emsp;2. 在頁面上方，你會看到一個黃色提示框，或者點擊上方的 [Pull requests] 分頁，然後點擊綠色的 [New pull request]。
<h4>&emsp;3. 確認比對方向無誤後，點擊 [Create pull request]。
<h4>&emsp;4. 輸入標題與簡單說明，再次點擊 [Create pull request] 送出！

<br><br><br>
🎉 大功告成！
送出後我們就會收到你的投稿通知，審核通過後就會合併到主倉庫中，你的梗圖就會正式加入機器人囉！
